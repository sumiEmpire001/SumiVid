# Sumi Vid 2.2 for Android

## Start watching

Open the app and allow video access, or use **＋** to select one video. Use the gear button for Settings. The three-dot library menu contains streaming, sorting and refresh. Each video row has its own options menu for favourites, playlists, details and sharing.

## Settings

Type in **Search settings** to find an option. Changes save immediately. Options that affect the library take effect when you return to it. Playback options apply when you return to the player or open the next video. Autoplay controls newly opened videos; it does not replace an explicit pause in the current session.

| Area | Controls |
| --- | --- |
| Playback | Resume, autoplay, automatic next, shuffle, speed, remembering speed, screen fit, seek interval, control timeout, orientation, screen awake, immersive full screen, pause on audio disconnect |
| Gestures | Double-tap seeking, horizontal seek, brightness, volume, floating video |
| Subtitles and audio | Enabled state, font size, colour, dark background, outline, bottom position, preferred audio and subtitle languages |
| Library | Thumbnails, default sort, minimum duration, hidden files, excluded folders, Android access settings |
| Appearance | Green, blue, lavender or amber accent; OLED black mode |
| Privacy | Save history on/off, clear history, reset settings |

Preferred languages depend on the tracks present in the video. Audio and subtitle selection remain available in the player. Load external SRT, VTT, SSA or ASS subtitles from **More → Load subtitle file**. Remove an attached subtitle using **More → Remove external subtitles**.

Folder exclusions hide videos from the library; you can still open an individual file manually. Turning off history hides Recent and Continue watching and stops saving new watch positions. Existing history remains until you clear it. Reset settings preserves favourites, playlists and watch history.

## Controls

Double-tap on the left or right to seek by your configured interval. Swipe horizontally to choose a position and release to seek. Swipe vertically on the left for brightness or on the right for volume. Disable any gesture in Settings. Lock blocks accidental taps. Float uses Android picture-in-picture, where supported and permitted, and supplies play/pause and seek controls.

Swiping from a screen edge temporarily reveals Android's bars in immersive mode. The Rotate control changes orientation for the current session; Settings controls the default orientation when returning to the player.

## Compatibility

Android 8.0 and later. This is a signed personal installation candidate with debugging disabled. Device testing is still required before production distribution. Supported file formats depend on the phone's decoders; there is no bundled software codec pack. Direct HTTPS files, HLS and DASH streams are supported by the playback engine. Casting, a private vault, online content accounts and a background-audio service are not included.

Install the new APK over v1.0, v1.1, v2.0 or v2.1. It uses the same signing certificate and app identifier, so Android can retain existing app data.
